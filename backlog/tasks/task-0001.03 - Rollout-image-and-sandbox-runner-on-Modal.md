## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The image is bh-02 at the pinned SHA plus the headless driver, named by digest. The runner starts a single-use Modal Sandbox per RolloutRequest with no Modal, Claude or Hugging Face credential, runs the task and returns the snapshot and transcript into the lab volume by content hash.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The runner refuses a request whose image digest is not the built one
- [ ] #2 The sandbox holds only the inference key, and no other secret
- [ ] #3 Snapshot and transcript land in the volume under their content hashes
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
### Order of work
1. Create the bh02-lab-inference secret. 2. Deploy serve, then rollout. 3. modal run probe_jail (TASK-0001.04). 4. Call rollout.image_digest twice and check the same digest comes back. 5. Run one rollout of paginate by hand and read its events and log in the artefacts volume.
### Risks
The image defined again inside a container must be the same image (same files, shipped under /lab/repo); if the digests differ every request is refused, which is safe but stops the lab. Reading a large work.tar back through the sandbox filesystem may hit a size limit (the sandbox already leaves caches and environments out).
### Proof
A Rollout JSON with ended replied or budget, and its snapshot in bh02-lab-artefacts.
<!-- SECTION:PLAN:END -->
