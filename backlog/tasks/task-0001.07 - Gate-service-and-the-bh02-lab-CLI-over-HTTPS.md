## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The gate is a small Modal web endpoint: run_battery(genome, model) fans out rollouts, waits for verdicts and returns the score with its noise band. The CLI is how the lab lead calls it, with a bearer token that can call the gate and nothing else.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 bh02-lab battery run prints the score, k, and the band as JSON
- [ ] #2 The gate refuses a request without the token, and the token reaches nothing else
- [ ] #3 The gate never loads a genome's plugins
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
### Order of work
Create the bh02-lab-gate secret; deploy gate; bh02-lab pins; bh02-lab battery run --k 2.
### Risks
GET /pins is slow the first time (it builds the rollout image); the CLI follows Modal's redirect and the gate caches pins per container.
### Proof
The battery run's JSON, complete, in the notes.
